# Iron Fist Gym

Landing page diseñada para un gimnasio de boxeo ficticio llamada **Iron Fist Gym**.

## Descripción

Este proyecto es una página estática creada con HTML y CSS. Presenta secciones de:
- Hero principal
- Clases disponibles
- Entrenadores
- Horarios
- Precios
- Contacto

La estructura del sitio está pensada para mostrar una experiencia clara, moderna y orientada a un gimnasio de combate.

## Estructura del proyecto

- `pages/index.html` — Página principal del sitio.
- `css/reset.css` — Reset de estilos básico para normalizar el renderizado entre navegadores.
- `css/variables.css` — Variables CSS para colores, tipografías y espaciados.
- `css/properties.css` — Reglas de diseño globales y utilidades.
- `css/styles.css` — Estilos específicos del layout, secciones y componentes.
- `img/` — Imágenes utilizadas en la página.
- `js/` — Carpeta preparada para scripts futuros (actualmente vacía).

## Cómo usar

1. Abrir `pages/index.html` en un navegador.
2. Navegar por la página usando el menú superior.
3. Si se desea editar, modificar los archivos de `css/` o `pages/index.html`.

## Tecnologías usadas

- HTML5
- CSS3

## Notas

- El proyecto es estático y no requiere servidor ni instalación adicional.
- La página incluye secciones de prueba y enlaces externos para mejorar la experiencia de presentación.
